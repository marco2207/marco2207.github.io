Privacy Policy – Hermes Personal

Last updated: October 14, 2026

Who uses this app

Hermes Personal is a private application used only by its owner (m.drago2207@gmail.com). It is not offered to the public.

Data accessed

With the owner's explicit consent via Google OAuth, the app may access the owner's Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Contacts data.

How data is used

Data is used solely to provide assistant features requested by the owner (for example reading or summarizing emails, listing calendar events, finding documents). Data is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens are stored locally on the owner's computer. Google user data is not stored on any external server operated by this app.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
